# Phase N 산출물 통합 관리표 (CBD 표준 템플릿)

- **프로젝트:** FoveaCore (`v1.9.3` 기준)
- **대상 단계:** `Phase [N]` — `[단계명 기입]`
- **사용 방법:**
  1. 이 파일을 각 Phase 폴더(`docs/phaseN/README.md` 또는 `00_deliverables_index.md`)에 복사한다.
  2. 작성하는 산출물은 `작성 여부`에 `O`를 표기하고, **코드 이름(`R3.md`, `D1.md`, `D5.md` 등)**으로 세부 문서를 생성한다.
  3. 해당 Phase에서 불필요한 산출물은 `작성 여부`에 `X`를 표기하고 `비고`에 생략 사유(예: RDBMS 미사용, UI 없음, 상위 문서 참조)를 적는다.
