# Phase 0 산출물 통합 관리표 (`CBD 표준 적용`)

* **프로젝트:** FoveaCore (`v1.9.3` 기준)

* **대상 단계:** `Phase 0` — 실험 환경, 데이터 격리 및 초경량 기준

* **규칙:** `O`는 이번 Phase에서 생성할 파일/산출물, `X`는 생성하지 않음을 의미합니다. 작성 대상 문서는 코드명(`R3.md`, `D1.md` 등)으로 관리하며, 기존 코드·설정·데이터 파일은 위치만 기록하고 별도 Markdown 문서를 만들지 않습니다. `X`로 표시한 산출물은 비고에 생략 또는 통합 사유를 명시합니다.
