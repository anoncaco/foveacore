# Phase 0 산출물 통합 관리표 (`CBD 표준 적용`)

* **프로젝트:** FoveaCore (`v1.9.3` 기준)

* **대상 단계:** `Phase 0` — 실험 환경, 데이터 격리 및 초경량 기준 (`T0 ~ T8`)

* **규칙:** 작성 대상 산출물(`O`)은 코드명(`R3.md`, `D1.md` 등)으로 세부 문서를 관리하고, 불필요한 산출물(`X`)은 비고에 생략 또는 대체 사유를 명시한다.
