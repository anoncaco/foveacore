## 1. 설정·프로파일 및 시드·예외 계약 (`config.py`, `utils/seed.py`, `core/exceptions.py`)

- **설정 상수 (`config.py`):** `INPUT_MAX_SIDE = 1024`, `ALLOWED_RESIZE_METHODS = {"adaptive_average"}`, `ALLOWED_PROTOCOLS = {"STRICT_1SHOT", "CONTINUAL", "REFERENCE_P3"}`, `ALLOWED_POLICIES = {"P0", "P1", "P2", "P3"}`, `ALLOWED_SMOKE_SCOPES = {"phase0_full_smoke", "general"}`.
- **센서 프로파일 (`SENSOR_PROFILES`):**
  - `F3`: `grid_size = 5`, `channels = 4`, `stroke_clue_available = True`
  - `F3_HIRES`: `grid_size = 97`, `channels = 4`, `stroke_clue_available = True`
- **명시적 예외 (`core/exceptions.py`):** `python -O`에서 무시되는 `assert`를 금지하고 `NumericalInstabilityError`, `ImmutabilityViolationError`를 사용한다.
- **시드·결정론 (`utils/seed.py`):** 5종 시드(`split_seed`, `episode_seed`, `generator_seed`, `model_seed`, `stream_order_seed`), `init_gpu_runtime()`, `set_gpu_determinism()`, `TorchDispatchMode` 기반 비결정론 CUDA 연산 검출, 스냅샷 복사 기반 `assert_reproducible()`.

## 2. 6대 불변 공통 인터페이스 (`core/contracts.py`, `schema_version = "1.0"`)

모든 인터페이스 클래스는 `@dataclass(frozen=True)`이며 `_freeze()`를 통해 `dict` → `MappingProxyType`, `list` → `tuple`, `np.ndarray` → `bytes` 백킹 읽기 전용 뷰(`object` dtype 거부), `torch.Tensor` → `ImmutableTensor`(`.detach().clone()` + SHA-256 변조 감지)로 보호된다.

| 클래스 | 핵심 필드 | 주요 검증 규칙 |
| :--- | :--- | :--- |
| `Observation` | `modality`, `source_id`, `location`, `features`, `observed_mask`, `confidence`, `cost`, `provenance` | 이미지 모달리티 시 `original_hw`, `processed_hw`, `preprocess_profile_id`, `sensor_profile`, `[0,1]` 좌표, `features` shape 대조; `provenance` 내 `stroke_clue_available` 키 금지 |
| `Action` | `modality`, `target`, `resolution`, `cost`, `window` | `modality` 비공백, `cost >= 0` |
| `Structure` | `entity`, `attribute`, `relation`, `embedding`, `uncertainty`, `source_evidence` | `uncertainty >= 0` 유한 실수 |
| `Hypothesis` | `concept_id: str`, `belief`, `supporting_evidence`, `contradicting_evidence` | `belief` ∈ `[0.0, 1.0]` 유한 실수 |
| `Prediction` | `modality_specific_distribution`, `candidate_observation`, `expected_cost` | `expected_cost >= 0`, `candidate_observation` 역직렬화 지원 |
| `Memory` | `concept_record`, `evidence_links`, `modality_views`, `versions`, `uncertainty` | 전 필드 `_freeze()` 불변 처리 |

## 4. 후속 요구사항 클래스 슬롯 (`REQ-P0-07` ~ `REQ-P0-10`)

| 요구사항 | 클래스 / 모듈 | 책임, 상태 모델 및 오류 계약 |
| :--- | :--- | :--- |
| `REQ-P0-07` | `PolicyCompatibilityValidator` | `ExecutionMode` × `ExperimentProtocol` × `PretrainingPolicy` × `split_name` 호환 매트릭스를 검증한다. `(STRICT_1SHOT, P3)`는 `PolicyConflictError`, P1 숫자 템플릿 유입은 `PretrainingLeakError`, 선언 개념 초과 support는 `OneShotBudgetExceededError`로 거부한다. |
| `REQ-P0-07` | `ReadOnlyInferenceGuard`, `PredictionCommitLog` | `INFER` 진입 시 `eval()`을 강제하고 `parameters()`·`buffers()`·`state_dict()`·`memory.json` 해시를 전후 비교한다. 1비트 변이도 `StateMutationError`로 차단하며, 에피소드 종료 시 초기 스냅샷을 복원한다. |
| `REQ-P0-07` | `BoundedStreamCursor` | 현재 인덱스 `t` 이하만 반환한다. `peek(t+k)`·직접 인덱싱 등 미래 접근은 `FutureDataAccessError`로 거부한다. |
| `REQ-P0-07` | `EpisodeSampler` | 에피소드가 선언한 개념 `C`마다 support 1장과 `Support ∩ Query == ∅`를 보장한다. 10,000장 풀 전체 전달과 `A,A,B` 같은 개념 누락 구성을 거부한다. |
| `REQ-P0-08` | `PixelKNNBaseline`, `HOGKNNBaseline` | `BlindSample`만 입력으로 받는 무튜닝 1-NN 기준선이다. 영벡터·동점·`NaN` 규칙을 공통 적용하고, HOG는 `scikit-image` 고정 파라미터를 사용한다. |
| `REQ-P0-09` | `ResourceProfiler` | `id()` + `(data_ptr, shape, stride)`로 중복을 제거하고 `total = active + frozen`, 1B/4GB 상한, 4종 저장량, Peak VRAM/RAM, FLOPs와 `unsupported_ops`를 계측한다. |
| `REQ-P0-10` | `HypothesisEvaluator` | MECE 4단계, Holm 보정, `H13-V`, `TECHNICAL_FAIL → DEFERRED`, `REFERENCE_P3` 배제를 구현한다. 산출물 writer의 파일·필드 계약은 `D4.md`에서 정의한다. |
