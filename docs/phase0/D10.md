## 공통 시험 명세 규약

- **필수 여부:** `TC-I-01`~`TC-I-03`은 모두 필수다.
- **사전 조건:** 검증 대상 변경본이 `verify` 환경에 반영되고 `configs/phase0.yaml`과 검증용 데이터가 준비돼 있다.
- **절차:** 각 행의 시험 절차·입력 조건을 순서대로 실행하고 합격 기준 및 연결 테스트 결과를 확인한다.
- **필요 환경:** 프로젝트 `.venv`의 Python·pytest·CPU 환경. smoke 실행은 고정 시드를 사용하며 GPU 사용 시 결정론 설정을 적용한다.
- **생략 사유:** 단순 CLI 워크플로우는 대상 워크플로우·연결 테스트·공통 조건으로 목적과 환경이 충분히 특정되므로 별도 컬럼을 두지 않는다.
