## 1. CLI 인터페이스 (`python -m foveacore`)

| 명령 | 입력 인자 | 처리 계약 | 종료 코드 |
| :--- | :--- | :--- | :---: |
| `validate` | `--config`, `--data-dir` | `init_gpu_runtime()` → `assert_no_forbidden_packages()` → `load_phase0_config()` (`YAMLError` 시 트레이스백 없이 `ERROR:`) → `validate_phase0_config()` → (`--data-dir` 지정 시 10종 분할·Vault·검증 메타데이터·OOD 8쌍 검증) | `0` (PASS) / `1` (오류) |
| `build-splits` | `--config`, `--out` | 설정 검증 통과 후 `out/raw` 생성 → MNIST 체크섬 검증/다운로드 → 10종 분할·Vault·메타데이터 분리 저장 → 교차 중복 검증 | `0` (완료) / `1` (실패, 출력 디렉터리 미생성) |
| `smoke-baseline` | `--episodes` | `REQ-P0-08`·`REQ-P0-10` 구현 후 `B0`/`B1` `BlindSample` + `ReadOnlyInferenceGuard` 무튜닝 실행 | 미구현(`2`) / 구현 후 `0`·`1` |

## 3. 설정·동결·산출물 입출력 계약 (`부록 4·5`)

- **`configs/phase0.yaml` 핵심 계약:** `smoke.scope` (`phase0_full_smoke` | `general`), `sensor.stroke_clue_available` (`bool`), `input.max_side = 1024` (`adaptive_average`), `forbidden_packages`.
- **`freeze_manifest.json` 필수 해시 필드:** `manifest_sha256` (자신을 제외한 Canonical JSON의 SHA-256), `data_split_hash`, `config_hash`, `checkpoint_hash` + `freeze_manifest.sha256` sidecar 및 독립 기준점(Git 태그/커밋/사전등록 해시) 대조.
- **`artifacts/<run_id>/` 표준 산출물 (`REQ-P0-10`):** `manifest.json`(5종 시드, GPU/CUDA/정밀도/결정론 설정, 자원 4종, `run_status`, `failure_reason`, `git_dirty` 등), `config.yaml`, `metrics.csv`, `summary.json`, `traces/inference.jsonl`(`stop_reason` 4종 또는 `N/A`), `traces/learning.jsonl`, `memory.json`, `checkpoint.pt`.
- **MNIST 분할·초기데이터 설계:** `D12` 문서는 만들지 않고, 10종 split·Vault·검증 메타데이터·OOD 8쌍 구성과 생성 절차를 이 문서와 `D5.md`에 통합한다.
- **사전 등록 보고서:** `experiments/preregistration_v1.9.3.md`에 가설·지표·MDE·검정력·비용 상한·분석 규칙을 구현 전에 잠근다.
- **실패 기록:** CLI·런 실패는 비정상 종료와 함께 `manifest.json`의 `run_status="FAILED"`·`failure_reason`을 남기고, 원자적 저장으로 이전 활성 산출물을 보존한다.
