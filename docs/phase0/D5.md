## 2. 데이터 3단 분리 아키텍처 (`T3`)

- **계층 1 — 공개 매니페스트 (`SplitManifest`):** `sample_id`, `split_name`, `sha256`, `phash`, `sealed_level`만 포함하며 정답·작성자·클래스 복원 필드를 전면 금지한다.
- **계층 2 — 검증 전용 기밀 메타데이터 (`ValidationMetadataStore`):** `class_id`, `writer_id`, `alphabet_id`, `source_id`를 분리 저장하며 `OODValidator` 내부 검증에서만 사용한다.
- **계층 3 — 정답 저장소 (`GroundTruthVault`):** `ground_truth_vault.json`에 `sample_id → label`만 보관하며 공개 `get()`을 두지 않고 `LabelAccessPolicy` + `SealGuard`를 통과한 `resolve_labels()` 내부에서만 읽는다.

## 3. Phase 0 비범위 경계 (`Non-Goals`)

- Phase 1~7 본체(F1~F4 풀링, GRU, DAS, World Model, Replay 엔진) 및 Phase 8~13(텍스트 어댑터, LLM 인터페이스, 웹 대시보드 UI)은 Phase 0에서 구현하지 않고 인터페이스 계약만 고정한다.
