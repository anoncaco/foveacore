## 2. Phase 1 진입 게이트 인수 시나리오 (`T6` 통합)

1. 저장소·환경 무결성 (`import foveacore`, `locks/phase0_requirements.lock`, 금지 패키지 미설치, `README.md` `v1.9.3`)
2. 데이터 격리·봉인·외부 분할 규칙 (ID/SHA-256 중복 0건, OOD 8쌍 격리, `SealGuard` 기준점·아티팩트 검증)
3. 정책 결합 검증 및 미래 데이터 선조회 차단 (`T4`)
4. `INFER` 전체 상태 불변성 및 라벨 권한 차단 (`T2`, `T4`)
5. GPU 결정론 및 동일 시드 재현성 (`T2`, `T5`)
6. `B0`/`B1` Smoke Test (`quick_smoke` + `phase0_full_smoke` 30 에피소드) (`T5`, `T8`)
7. GPU 자원 계측 정확성 (`data_ptr` 중복 제거, `<= 1B`, `<= 4GB`) (`T6`)
8. Manifest·산출물·`git_dirty` 차단·실패 복구 7종 (`T7`)
9. 통계 판정기 (`MECE`, `H13-V`, `TECHNICAL_FAIL -> DEFERRED`, `REFERENCE_P3` 배제, 입력 예외) (`T8`)
10. 사전등록 (`experiments/preregistration_v1.9.3.md`) 및 `python -m foveacore validate --config configs/phase0.yaml` 최종 PASS + Phase 1 센서 인수 계약 fixture 통과 (`T8`)
