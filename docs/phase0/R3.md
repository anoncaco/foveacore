## 1. 초기 사전 학습 조건 (`P0 ~ P3`) 기준표

| 조건 | 사전 학습 데이터 | 목표 숫자 직접 경험 | 역할 및 가설 판정 허용 여부 | Phase 0 코드 강제 방식 |
| :--- | :--- | :--- | :--- | :--- |
| **P0** | 없음 | 클래스별 1장 (총 10장) | 사전 지식 없는 순수 1-shot (보조; $\Sigma_0 = I$) | `PretrainingPolicy.P0`, `STRICT_1SHOT` 허용 |
| **P1 (핵심)** | 합성 선·곡선·그래프 | 클래스별 1장 (총 10장) | 기하 구조 사전 지식 기반 엄격 1-shot (`H1~H6` 주 판정 기준) | `PretrainingPolicy.P1`, 숫자 템플릿 유입 시 `PretrainingLeakError` (`T4` 예정) |
| **P2** | P1 + 비숫자 문자 | 클래스별 1장 (총 10장) | 비숫자 손글씨 도메인 전이 (보조) | `PretrainingPolicy.P2`, `p2_non_digit`·`non_digit_dev`와 OOD 8쌍 격리(`T3`) |
| **P3** | 숫자 포함 데이터 | 클래스별 1장 추가 제공 | 동일 도메인 상한 참고군 (`H1~H6` 입증 근거 제외) | `(STRICT_1SHOT, P3)` 차단 및 `eligible_for_h1_h6 = False` (`T4` 예정) |
